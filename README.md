# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」の1ページ完結型コーポレートサイトです。
掲載されている会社名・人物・実績・メールアドレスはすべて架空のものです。

## 概要

- 構成: `index.html` 1ファイル(CSS・JavaScript もすべて内包)
- 外部ライブラリ・ビルド作業は不要
- レスポンシブ対応(スマートフォン幅でも表示可能)

### ページの構成

| セクション | 内容 |
| --- | --- |
| ヘッダー / お知らせバー | ナビゲーションと、直下に表示されるお知らせ(4秒ごとに切り替わり) |
| ヒーロー | キャッチコピーと問い合わせへの導線 |
| 事業内容 | クラウド開発、AI、モバイルアプリなど6つのサービス |
| 強み | 実績の数字と3つの特徴 |
| 開発実績 | 3件の事例紹介 |
| 会社情報 | ミッションと会社概要 |
| お問い合わせ | メールアドレスへのリンク |

## index.html を開く手順

### 方法1: ブラウザで直接開く

1. このリポジトリを取得し、ディレクトリへ移動します。

   ```sh
   cd company-site
   ```

2. `index.html` をブラウザで開きます。

   - macOS: `open index.html`
   - Windows: `start index.html`
   - Linux: `xdg-open index.html`
   - または、ファイルをブラウザにドラッグ&ドロップします。

### 方法2: ローカルサーバーで開く

Python 3 が入っていれば、次のコマンドで起動できます。

```sh
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> にアクセスしてください。終了するときは `Ctrl + C` を押します。
